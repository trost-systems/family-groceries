# Hummlist with Alexa (German only for now)

You can add items to Hummlist with Alexa, and have Alexa read your list out, using the Alexa skill "Hummlist". Right now this only works in German: the skill understands German only, your Alexa device has to be set to German, and the setup guide is in German. The skill is still in a beta test, so you need an invitation link.

If you're comfortable with German, you can follow the German guide: [Hummlist per Alexa: Skill einrichten](/de/anleitungen/alexa)

You can disconnect Alexa at any time in the Alexa app, or in Hummlist under **More** → **Access**.

We'll update this page if that changes.
