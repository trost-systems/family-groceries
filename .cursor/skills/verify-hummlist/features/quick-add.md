# Quick add

The add bar sits at the bottom of the list screen, above the tabs, with the hint „Was brauchst du?“ / "What do you need?". Typing into it, or tapping it, opens the add sheet („Hinzufügen“ / "Add") over a dimmed list. The sheet offers rows for what was typed: first the line itself as typed („Wie getippt“), then things the household bought before, other packs, kinds, sizes and brands, and words from the catalogue. Enter takes the first row, a tap takes any row. After an add the field empties, the cursor stays, and a note in the sheet says what was added and where, with „Rückgängig“. The user can set the store and the category for the next row with two chips. With the field empty the sheet offers what is due again.

## Sub-features

- `qa-autofocus` the cursor is in the add bar when the list opens, on desktop and web; phones wait for a tap. The bar shows a round "+" disc left of the field.
- `qa-sheet` the sheet opens on the first keystroke or a tap on the field. It has a header „Hinzufügen“ with a „Schließen“ button, the two chips, and the rows. While it is open the tab bar gives way to the line „Antippen fügt hinzu · ↵ nimmt den ersten Vorschlag“ / "Tap to add · ↵ takes the first suggestion".
- `qa-rows` each row is one button named "<quantity> <name>, <source>, <brand>, <detail…>, <store>" (empty parts are left out; a bare count reads "2×", a count with unit reads "2 l"). Sources: „Wie getippt“ / "As typed", „Schon mal gekauft“ / "Bought before", „Andere Packung“ / "Other pack", „Andere Sorte“ / "Other kind", „Andere Größe“ / "Other size", „Andere Marke“ / "Other brand", „Aus dem Katalog“ / "From the catalogue", „Wieder fällig“ / "Due again", „Zuletzt verwendet“ / "Recently used". While text is typed the first row is highlighted and carries a return-key glyph (it is what Enter takes); with the field empty no row has them, since Enter then adds nothing.
- `qa-matching` what the server offers for the typed text (at most 8 rows, no row twice, asked about 120 ms after the last keystroke): the typed line, read into name, brand, details and quantity (always first); up to 3 „Schon mal gekauft“ rows, the household's items from the last year whose name matches the typed name (2 or more letters), with their old brand, details and quantity (a quantity typed now wins); up to 2 „Andere Packung“ / „Andere Sorte“ rows made from details bought before with the same name ("Big Pack", "laktosefrei"); 2 „Andere Größe“ rows when a "Größe n" is typed (n+1, n−1, between 1 and 8); up to 3 „Andere Marke“ rows (brands bought before with that name, then known brands of that product); up to 3 „Aus dem Katalog“ rows, dictionary words that match the LAST typed word (2 or more letters). A name matches, best first: the same name; it starts with the typed text; it has the typed text inside, from 4 letters („milch“ finds Hafermilch); or it is a typo of it, from 3 letters, with the same first letter and at most one wrong, missing or extra letter up to 5 letters, two from 6 („Hafermlch“, „Tomatn“). Under 3 letters only the start counts. Within a source exact and start matches come newest first (history) or shortest first (catalogue), inside-word and typo matches most similar first. Rows whose item is already open on the list are dropped, except the typed row.
- `qa-enter` Enter (also numpad Enter) adds the first row and keeps the cursor for the next item. The sheet stays open. If the rows have not arrived yet Enter waits for them (up to 3 s, then falls back to the line parsed on the device).
- `qa-quantity` a leading amount becomes the quantity: "2 Äpfel" gives Äpfel with 2, shown "2× Äpfel"; "2 l Milch" gives Milch 2 l; "6x Eier" gives 6; "500 g Hack" and "Hack 500 g" both give 500 g; German number words one to twelve count too ("zwei Gurken", "eine Packung Eier"; "ein halbes Brot" gives 1/2; "anderthalb Liter Milch" gives 1,5 Liter); "6 x 1,5 l Wasser" stays one multipack token "6x1,5l". A trailing amount with a unit counts ("Hack 500 g"); a trailing count works as "Karotten x2" or "Karotten 2x", and a bare number at the end ("Karotten 2", "carrots 2") is the quantity only when it is 1 to 20, does not follow a size or unit word (Größe, Nr., Stufe, size, mAh, ml …) or touch letters, and the rest is a word the dictionary knows or a name the household had before (job 61, `supabase/tests/quantity_parse.tsv`): "Windeln Größe 4", "Vitamin D3", "7up" and "Büroklammern 100" keep their number in the name. The same rule holds offline, in MCP, Siri and Alexa. The row shows the quantity after the name, "Karotten · 2"; a row tapped while the rows for the new text are still loading takes the quantity typed now. Units include kg, g, l, ml, cl, Stück, Packung, Dose, Flasche, Bund, Becher, Glas, Tüte, Beutel, Netz, Kiste, Kasten, Rolle, Tafel, Stange and more.
- `qa-details` brand, details and store are read out of the typed line: "Windeln Pampers Größe 3" gives the row „Windeln, Wie getippt, Pampers, Größe 3, dm“ (a drugstore item or the brand's own store picks dm; a remembered store for the name wins).
- `qa-tap-row` a tap on any row adds it with every field it shows (quantity, brand, details, store, category) and keeps the cursor in the field.
- `qa-chips` the store chip („Laden: automatisch“ / "Store: automatic", or „Laden: <name>“ / "Store: <name>" once the rows or a pick decide it) and the category chip („Kategorie: automatisch“ / "Category: automatic", or „Kategorie: <name>“ / "Category: <name>") fold out their options inline: the stores, the option „Ohne Laden“ / "No store", and the categories. A pick applies to the next row taken, whichever it is, then resets. Rows tell their own store with a small badge when it differs from the chip. A pick that differs from the guess is remembered for that name (see the stores feature).
- `qa-added` after an add the note reads „✓ Hinzugefügt: <name> → <store>“ / "✓ Added: <name> → <store>" (without „ → <store>“ when no store) with a „Rückgängig“ / "Undo" button, until the next keystroke. Undo deletes the item again, and the cursor goes back to the field.
- `qa-duplicate` an item with the same name, brand and details already open on the list is not added again: the note reads „<name> steht schon auf der Liste“ / "<name> is already on the list", with no check mark and no undo.
- `qa-dedupe-hint` an item whose spelling variant or synonym is open (Karotten with Möhren open) is added anyway; once the server confirms it, the note gains a line „Möhren steht schon auf der Liste“ with „Zusammenführen“ / "Merge". Merging keeps the open item with merged quantities ("500 g" + "1 kg" = "1,5 kg") and shows „Zusammengeführt: 1,5 kg Möhren“ / "Merged: 1,5 kg Möhren" with „Rückgängig“ / "Undo", which brings both back. With the sheet closed the same hint is a snackbar for 6 seconds.
- `qa-due` with the field empty the sheet lists the due items as „Wieder fällig“ rows, then items used in the last 30 days as „Zuletzt verwendet“ rows, 10 rows in all (see the usuals feature); with neither it says „Tippe, um Vorschläge zu sehen“ / "Type to see suggestions".
- `qa-offline` without a reachable server the rows are made on the device: the typed line, then up to 5 of the household's earlier items („Schon mal gekauft“) from the cached list, matched as the server matches: same name, start, a word's start, inside (from 4 letters), typo (from 3 letters), so „Hafermlch“ and „milch“ find Hafermilch offline too.
- `qa-clear` a ✕ in the bar (tooltip „Eingabe leeren“ / "Clear input") appears while the sheet is open and text is typed; it empties the field and keeps the sheet open.
- `qa-close` „Schließen“ / "Close", Escape, or a tap on the dimmed list closes the sheet and clears the field and the chip picks. Opening again starts blank. After a close, a tap on the field or typing opens the sheet again.
- `qa-length` the field takes at most 120 characters.

## How to get to it (user POV)

- Open the app signed in to a household; the „Liste“ / "List" tab is the home screen and the bar „Was brauchst du?“ / "What do you need?" is at its bottom.
- Type, or tap the bar, then press Enter or tap a row.
- Tap the chip „Laden: automatisch“ / "Store: automatic" or „Kategorie: automatisch“ / "Category: automatic" before taking a row.
- Tap „Rückgängig“ / "Undo" in the note after an add.
- Close with „Schließen“ / "Close", Escape or a tap on the dimmed list.
- Tap the empty bar to see what is due again.
- On iOS and Android the bar also has a microphone (see the dictation feature).

## Driving it with Playwright

Preconditions:

- Signed in as a member of the seeded household (analytics consent declined, onboarded), viewport 480x900 or 390x844, on the list tab. Make sure the names used below are not open on the list (tick or delete them first). Stores: the e2e specs create their household with the default stores (dm, Lidl, Edeka) through `signUpWithHousehold`; the baseline „Familie Brandt“ has the same three, and none of its 13 items has a store.
- Existing coverage: `e2e/tests/add-sheet.spec.ts`, `e2e/tests/autofocus.spec.ts`, `e2e/tests/suggestions.spec.ts`, `e2e/tests/dedupe.spec.ts`, `e2e/tests/list.spec.ts` (duplicate note), run via `scripts/verify.sh --only e2e -- tests/<file>`.
- Locators: `addField(page)` is `getByRole('textbox', { name: 'Was brauchst du?' })`; `addSheet(page)` is `getByRole('group', { name: 'Hinzufügen', exact: true })`; rows are buttons in the sheet whose name matches `, (Wie getippt|Schon mal gekauft|Andere Packung|Andere Sorte|Andere Größe|Andere Marke|Aus dem Katalog|Wieder fällig|Zuletzt verwendet)(,|$)`; `addedNote(page, line)` is `addSheet(page).getByText(line, { exact: true })`.

- **Autofocus.** Reload the page on the list. `await page.reload(); await expect(addField(page)).toBeFocused()`. The sheet is closed (`addSheet(page)` count 0) and the list is visible above the bar.
- **Open and type.** Click the field, then `await typeInto(addField(page), 'Windeln Pampers Größe 3')`. Observable result: `addSheet(page)` is visible; the first row has the accessible name `Windeln, Wie getippt, Pampers, Größe 3, dm` (the store part depends on the household's stores); `page.getByText('Antippen fügt hinzu · ↵ nimmt den ersten Vorschlag')` is visible.
- **Enter takes the first row.** `await typeInto(addField(page), 'Butter'); await page.keyboard.press('Enter')`. Observable result: `addedNote(page, /^✓ Hinzugefügt: Butter\b/)` is visible, `addField(page)` has value '' and is focused (`toBeFocused()`), the sheet is still open. As a second view read the `items` table through the API for status 'active' and name 'Butter'.
- **Quantity.** `typeInto(addField(page), '2 l Milch')`; the first row is named `2 l Milch, Wie getippt`. With '2 Äpfel' it is `2× Äpfel, Wie getippt`; with 'zwei Gurken' it is `2× Gurken, Wie getippt`. Enter, then the item's quantity is '2 l' / '2' / '2' in the API.
- **Tap a suggestion.** Type a prefix of something bought before (`Mi` with an old Milch), click the row `getByRole('button', { name: /^2 l Milch, Schon mal gekauft/ })` inside `addSheet(page)`. Observable result: the note `✓ Hinzugefügt: Milch`, focus still in `addField(page)`.
- **Chips.** With text typed: `await addSheet(page).getByRole('button', { name: /^Laden: / }).click()`, then `await addSheet(page).getByRole('button', { name: 'Lidl', exact: true }).click()`. Observable result: a button named `Laden: Lidl` is visible; click a row; the new item's store is Lidl in the API. Category: `getByRole('button', { name: /^Kategorie: / })`, then the category name (for example 'Getränke'). `Ohne Laden` is the no-store option.
- **Undo.** After an add, `await addSheet(page).getByRole('button', { name: 'Rückgängig' }).click()`. Observable result: the note goes, the API shows no active item of that name, the field is focused again after about 150 ms (`page.waitForTimeout(150)` as the specs do).
- **Duplicate.** Add 'Butter' (Enter), type 'Butter' again and Enter. Observable result: `addedNote(page, 'Butter steht schon auf der Liste')` is visible, there is no 'Rückgängig' button in the sheet, and the API still shows one active Butter.
- **Due and recently used.** See the usuals feature; rows are named like `Butter, Wieder fällig` and `Hafermilch, Zuletzt verwendet`.
- **Typo and part of a word.** Tick an item (`addItem(page, 'Hafermilch')`, `tick(page, 'Hafermilch')`), then `typeInto(addField(page), 'Hafermlch')` (or 'milch'). Observable result: the button `Hafermilch, Schon mal gekauft` is in the sheet; click it: the note `✓ Hinzugefügt: Hafermilch`, `addField(page)` focused with value '' (`suggestions.spec.ts`, test "a typo or part of a word finds what was bought before …").
- **Close.** Press Escape in the field (`closeSheet(page)` in helpers) or click `addSheet(page).getByRole('button', { name: 'Schließen' })`. Observable result: `addSheet(page)` count 0 and the field is empty. Click the field again and type: the sheet opens again and the first row is the typed one.
- **Offline.** `cutOff` the page from Supabase, type a prefix of an earlier item: rows are `<name>, Schon mal gekauft` from the cache (`suggestions.spec.ts`, test "suggestions come from the device cache when Supabase is unreachable").

## Gotchas

- Use `typeInto` for typing: synthetic key events drop umlauts. Click the field first so the sheet is open, then type (text inserted during the opening tap can land in the DOM input but not in the app).
- While the sheet is open the list under the dimmed layer is out of reach; a click there closes the sheet. Close the sheet (Escape) before acting on list rows. Escape takes focus away from the field.
- Prefer Escape over „Schließen“ in recipes that go on typing; the specs pin that after „Schließen“ the next tap and typing still reopen the sheet, including a key typed before the next frame (`add-sheet.spec.ts`).
- After a tap on a row, a chip or Undo the field regains focus after about 50 ms on web; wait ~150 ms before typing without a click.
- Rows arrive about 120 ms after the last keystroke; wait for the row you want by name before clicking, and match rows by name regex, not index: the order depends on the household's history and the catalogue.
- `getByText` on a snackbar finds only a short-lived screen-reader copy; use `actionSnackBar(page, '<text>')`. The dedupe hint is a group named „Möhren steht schon auf der Liste“ in the sheet's note, a snackbar after closing.
- The note's „Rückgängig“ and the hint appear only until the next keystroke or the next add.
- A chip pick is remembered for that item name (store or category memory); later adds of that name land there. `helpers/launch.sh --fresh` (or `scripts/fg teardown <run>`) removes the run's household with its memory; use a fresh run for repeatable recipes.
- On phones the cursor does not come up on open; only a tap shows the keyboard. The iPhone behaviour is covered by `e2e/tests/iphone.spec.ts` in WebKit as an iPhone, not by a normal Chromium run (tests: one tap opens the sheet with the field focused; one tap after a tapped suggestion brings the keyboard back).
- The microphone does not exist on web, see the dictation feature.
- Typo rows were driven on 2026-11-01: „Hafermlch“ offers „Hafermilch, Aus dem Katalog“. A word already open on the list is not offered again, so „Joghrt“ offers „Jogurt“ when Joghurt is on the list.
- A new row can land below the fold (Tiefkühl, Haushalt); scroll to it (`reveal`) before asserting.
- The ✕ in the bar is a button named „Eingabe leeren“ (seen in the ARIA snapshot of a drive, 2026-11-01).
- The catalogue („Aus dem Katalog“) is German in both UI languages: with English UI, "Jogh" offers „Joghurt“ and "Yogh" offers nothing (driven 2026-11-01). English names still sort into the right category through the classifier's synonyms.
- Item writes are optimistic: the row shows before the server has it. Assert stored state through the API and poll.
