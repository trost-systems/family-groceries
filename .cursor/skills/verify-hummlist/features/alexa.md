# Alexa skill (beta, not certified)

A household member can say „Alexa, sag Hummlist, füg Milch und Eier hinzu“ and the items land on the household's list, sorted into categories like typed ones, visible to every member within seconds; Alexa reads back what it added. „Alexa, frag Hummlist, was auf der Liste steht“ reads the open items. The skill speaks German (de-DE) and English (en-US, en-GB, en-AU, en-CA, en-IN; the Alexa device's language picks one), is in beta and not certified by Amazon (alexa-certification hold): it is not in the Alexa Skill Store for everyone. A user gets it today only by an invitation to the beta test (the invitation link comes from Peter, who needs the email address of the user's Amazon account), then enabling the skill and linking the account in the Alexa app. Nothing needs Premium today.

## Sub-features

- `alexa-add` adds the items of one phrase (several, quantities, umlauts) to the linked user's household and reads them back. A count said after the name, as a word or digits („Karotten zwei“, „Karotten 2“, "carrots two"), is the quantity, like one said before it (job 89).
- `alexa-duplicate` names open items without adding them again.
- `alexa-similar` a spelling variant or synonym already open is added anyway and named.
- `alexa-read` reads the open items in aisle order, at most ten, then „und N weitere“; an empty list has its own sentence.
- `alexa-reprompt` asks once when nothing was understood, then gives up; nothing is added.
- `alexa-unlinked` asks to link the account (a link card in the Alexa app) when there is no link or it was cut.
- `alexa-link` account linking: Alexa app → Skills → Hummlist → „Zur Verwendung aktivieren“ / „Konto verknüpfen“ opens the Hummlist consent page „Zugriff erlauben?“ for „Amazon Alexa“; after „Erlauben“ it shows „Verbunden“ / „Fertig, du kannst zu Amazon Alexa zurückkehren.“ until the Alexa app takes over; afterwards Mehr → Zugänge lists „Amazon Alexa“ under „Verbundene Apps“.
- `alexa-revoke` Alexa is cut off at once by „Amazon Alexa trennen“ then „Trennen“ in Zugänge, or by disabling the skill in the Alexa app; linking again restores it. Disabling the skill also removes „Amazon Alexa“ from Zugänge at once („Noch keine App verbunden.“ when it was the only app). What the server kept about the connection (link, add counter) goes at once either way; a connection unused for 12 months (also one only unlinked in the Alexa app) is removed with its Zugänge entry by a daily job.
- `alexa-help` help and stop.
- `alexa-verify` requests not signed by Amazon, stale or for another skill are refused (HTTP 400) before anything is read.

## How to get to it (user POV)

- Today (beta): get the beta invitation link from Peter, accept it with the Amazon account used for Alexa, open the skill „Hummlist“ in the Alexa app (its icon carries the note „dev“ in test), tap „Zur Verwendung aktivieren“, sign in to Hummlist, check „Zugriff erlauben?“ shows „Amazon Alexa“ and tap „Erlauben“. Needs an Alexa device set to German or English, a Hummlist account, a household, and the Alexa app. Published guide: „Hummlist per Alexa: Skill einrichten“ on hummlist.com.
- Invocation: „Alexa, sag Hummlist, …“, „Alexa, frag Hummlist, …“, „Alexa, öffne Hummlist“. Invocation name: „hummlist“. Only these patterns reach the skill: „Alexa, setz Milch auf die Hummlist“ goes to Alexa's own lists („Ich konnte keine Liste finden unter Hummlist“). Alexa may mishear the name („Homelist“, „Hamlist“, „Ich weiß nicht“); the guide says to say it clearly in two syllables, „Humm-list“, or start with „Alexa, öffne Hummlist“.
- Skill icon: the Hummlist app icon (yellow hex ring with a check on cobalt), 108 and 512 px, generated by `design/app-icon/build.mjs`.
- Add phrases (sample utterances): „füg {items} hinzu“, „füge {items} hinzu“, „füg {items} zur liste hinzu“, „füg {items} zur einkaufsliste hinzu“, „{items} hinzufügen“, „setz {items} auf die liste“, „pack {items} auf die liste“, „setz {items} drauf“, „pack {items} drauf“, „schreib {items} drauf“, „füg noch {items} hinzu“, „ich brauche noch {items}“, „schreib {items} auf“, „trag {items} ein“, „notier {items}“, „wir brauchen {items}“, „ich brauche {items}“, „{items} auf die liste“, „dass wir {items} brauchen“ and more. Read phrases: „was steht auf der liste“, „was auf der einkaufsliste steht“, „was wir brauchen“, „was muss ich kaufen“, „lies die liste vor“, „die liste“ and more. Item names given in lower case are capitalized the German way („milch ohne laktose“ becomes „Milch ohne Laktose“).
- English (an Alexa device set to English): "Alexa, ask Hummlist to add milk and eggs", "Alexa, tell Hummlist we need milk", "Alexa, ask Hummlist what's on the list", "Alexa, open Hummlist". Replies: "I put milk and eggs on Hummlist.", "Already on Hummlist: milk.", "There are 3 things on your Hummlist: milk, eggs and bread." (more than ten: "… and 2 more."), "Your Hummlist is empty.", launch "What should go on the list?", stop "Bye for now.", unlinked "Please link your Hummlist account in the Alexa app first. I sent you a card there." (`supabase/functions/alexa/speech_en.ts`). Names are stored as heard ("milk"), like Siri in English.
- Exact spoken replies in German:
  - one item added: „Ich habe Milch auf die Hummlist gesetzt.“
  - several added: „Ich habe Milch und Eier auf die Hummlist gesetzt.“ / „Ich habe Milch, Eier und Brot auf die Hummlist gesetzt.“
  - mix: „Ich habe Eier auf die Hummlist gesetzt. Schon auf der Hummlist: Milch.“
  - already there only: „Schon auf der Hummlist: Milch.“
  - similar (a spelling variant or synonym is open, the new item is added anyway): it joins the „Schon auf der Hummlist:“ sentence after the exact ones, each name once (job 68): „Ich habe Karotten auf die Hummlist gesetzt. Schon auf der Hummlist: Milch und Möhren.“
  - units are spoken out: 2 l becomes „2 Liter“, kg „Kilo“, g „Gramm“, ml „Milliliter“.
  - more than thirty things: the confirmation is followed by „Mehr als dreißig auf einmal gehen nicht; sag den Rest bitte noch einmal.“
  - read: „Auf der Hummlist stehen 3 Sachen: Milch, Eier und Brot.“ / one item „Auf der Hummlist steht eine Sache: Milch.“ / more than ten: „Auf der Hummlist stehen 12 Sachen: a, b, … und 2 weitere.“ (exactly one more: „und eine weitere“) / empty: „Die Hummlist ist leer.“
  - open (launch): „Was soll auf die Liste?“ (reprompt „Was soll auf die Liste? Sag zum Beispiel: Milch und Eier.“)
  - help: „Mit Hummlist setzt du Sachen auf eure Einkaufsliste. Sag zum Beispiel: füg Milch und Eier hinzu. Oder frag: was steht auf der Liste? Was möchtest du?“ (reprompt „Was soll auf die Liste? Oder frag: was steht auf der Liste?“)
  - stop / cancel: „Bis bald.“
  - not understood, first time: „Das habe ich nicht verstanden. Was soll auf die Liste?“ (reprompt „Was soll auf die Liste? Sag zum Beispiel: Milch und Eier.“); second time: „Das habe ich leider nicht verstanden. Ich habe nichts auf die Hummlist gesetzt.“
  - not linked / cut off: „Bitte verknüpfe zuerst dein Hummlist-Konto in der Alexa-App. Ich habe dir dort eine Karte dazu geschickt.“
  - no household: „Du bist noch in keinem Haushalt. Leg in der Hummlist-App einen an oder tritt einem bei, dann klappt es auch mit Alexa.“
  - too long: „Das war zu lang. Sag höchstens dreißig Sachen auf einmal. Ich habe nichts hinzugefügt.“
  - too many requests: „Das waren gerade sehr viele Sachen auf einmal. Warte bitte eine Minute, dann geht es weiter. Ich habe nichts hinzugefügt.“
  - add failed: „Entschuldigung, das hat gerade nicht geklappt. Ich habe nichts hinzugefügt. Versuch es bitte gleich noch einmal.“
  - read failed: „Entschuldigung, ich komme gerade nicht an die Hummlist. Versuch es bitte gleich noch einmal.“
  - The add and read answers also appear as a card titled „Hummlist“ in the Alexa app.
- Skill store text (not live): „Eure gemeinsame Einkaufsliste: Sachen per Zuruf auf die Hummlist setzen.“ English: "Your household's shared shopping list: add things to Hummlist by voice." The package is set to every country (`alexa/skill-package/skill.json`, `isAvailableWorldwide`); as a beta it reaches only invited testers.

## Driving it with Playwright

Preconditions:

- Alexa itself cannot be driven. Only the skill's server side is, over HTTP against the LOCAL stack, as `e2e/tests/alexa.spec.ts` and `alexa-en.spec.ts` do. `helpers/launch.sh` already runs `scripts/alexa-test-ca.sh` before it starts the stack (`supabase_up` in `scripts/lib.sh`); run it by hand only for a stack started some other way, then restart that stack. Then use `scripts/alexa-say.sh` or the helpers in `e2e/tests/alexa-helpers.ts` (`alexaRequest`, `addIntent`, `readIntent`, `postToAlexa`, `say`, `registerAlexaClient`, `linkAccount`). Never call production.
- The spec signs up its own accounts (peter and lea, max and nina) and needs no seed. Run: `scripts/verify.sh --only e2e -- tests/alexa.spec.ts tests/alexa-en.spec.ts` (3 + 1 tests). By hand on the demo-familie seed, link mia and watch the list in noah's browser context instead of lea's.

- **Link the account (UI part).** `linkAccount(...)` registers a confidential OAuth client named like Alexa and opens the authorize URL with PKCE and the Alexa redirect `https://layla.amazon.com/api/skill/link/<vendor id>` in the signed-in page. The consent page shows „Zugriff erlauben?“ and `getByText('Amazon Alexa')`; click `getByRole('button', { name: 'Erlauben' })`; the callback carries a code; exchange it for an access token with HTTP Basic.
- **Zugänge shows it.** `openMore(page, 'Zugänge')`; `page.getByText('Amazon Alexa').first()` is visible under „Verbundene Apps“.
- **Add.** `say(token, 'Milch und Eier')` returns the speech (`scripts/alexa-say.sh --url "$API" --token "$TOKEN" "Milch und Eier"` prints JSON with `.response.outputSpeech.text`): „Ich habe Milch und Eier auf die Hummlist gesetzt.“; in the partner's page `itemRow(lea, 'Eier')` is visible within 5 seconds without reload; both are under category „Kühlregal“ (`getByRole('heading', { name: 'Kühlregal' })`).
- **Duplicate / read / re-prompt / launch.** `say(token, 'Milch')` gives „Schon auf der Hummlist: Milch.“; `scripts/alexa-say.sh … --read` gives „Auf der Hummlist stehen N Sachen: …“; `say(token, 'äh')` then `--retry` gives the two not-understood sentences, `shouldEndSession` false then true; `--launch` with no token gives the link sentence and a `LinkAccount` card.
- **Revoke.** `getByRole('button', { name: 'Amazon Alexa trennen' }).click()`, `getByRole('button', { name: 'Trennen', exact: true }).click()`, `getByText('Noch keine App verbunden.')`; the next add answers the link sentence and adds nothing; the refresh token is refused. Or `--disable` (SkillDisabled); Zugänge then shows „Noch keine App verbunden.“ as well. Database: `alexa_links` and `alexa_rate` have no row for the user afterwards (`alexaRows` in e2e/tests/alexa.spec.ts).
- **Verify.** `--unsigned` and `--stale` answer HTTP 400 (`missing_signature`, `stale_timestamp`); no item is added.

## Gotchas

- The beta status is the product reality: do not say the skill is in the Alexa Skill Store or certified. The hold `alexa-certification` stays until Amazon certifies it.
- Two languages: de-DE is German; every en-* locale gets the same English model and replies. A request without a locale is German.
- A stack started before `scripts/alexa-test-ca.sh` ran does not trust the test CA: every signed request answers 400 before any intent. Restart the local stack after running the script.
- The local function trusts the test CA only in a local stack; a hosted project refuses it, and `scripts/alexa-say.sh` cannot reach a hosted project.
- No Premium lock: Alexa is free for good (Legal N-27). With the integration-lock switch on, Alexa still adds (`e2e/tests/integration-lock.spec.ts`), and Zugänge never shows „Pausiert“ under Amazon Alexa.
- Each request logs one line, `alexa: <type> <intent|-> <locale|-> linked=<bool> -> <kind>`, with no ids, tokens or item names (`docs/ALEXA.md`, "Request log").
- Every linking run adds a row „Amazon Alexa …“ to Zugänge; after a second link, match the row with `.first()` or count the rows.
- Real Alexa voice, the Alexa app linking screens and the beta invitation cannot be checked here. unverified (needs a real device and an Amazon account).
