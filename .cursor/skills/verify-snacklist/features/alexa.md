# Alexa skill (beta, not certified)

A household member can say „Alexa, sag Snacklist, füg Milch und Eier hinzu“ and the items land on the household's list, sorted into categories like typed ones, visible to every member within seconds; Alexa reads back what it added. „Alexa, frag Snacklist, was auf der Liste steht“ reads the open items. The skill speaks German (de-DE) and English (en-US, en-GB, en-AU, en-CA, en-IN; the Alexa device's language picks one), is in beta and not certified by Amazon (alexa-certification hold): it is not in the Alexa Skill Store for everyone. A user gets it today only by an invitation to the beta test (the invitation link comes from Peter, who needs the email address of the user's Amazon account), then enabling the skill and linking the account in the Alexa app. Alexa adds to and reads the first list of the user's default household (job 169b: picked under „Siri, Alexa & KI nutzen“ in the household switcher). Nothing needs Premium today.

## Sub-features

- `alexa-add` adds the items of one phrase (several, quantities, umlauts) to the linked user's household and reads them back. A count said after the name, as a word or digits („Karotten zwei“, „Karotten 2“, "carrots two"), is the quantity, like one said before it (job 89). Up front, a name that starts with a number word keeps it, as typed: „Drei Glocken Nudeln“ is one item, „drei Äpfel“ 3 Äpfel (job 159, the `name` rows of `supabase/tests/number_words.tsv`).
- `alexa-named-list` (job 207) `AddToListIntent` („füge {items} zur {list} Liste hinzu“) or a list phrase at the end of `AddItemIntent`'s items puts the items on that list: „Ich habe Luftballons auf die Liste Geburtstag gesetzt.“; unknown or ambiguous → the default list and Alexa says so; with several lists every read-back names the list. Driven locally with `scripts/alexa-say.sh --list Geburtstag Luftballons`; the development skill needs a dev deploy first.
- `alexa-duplicate` names open items without adding them again.
- `alexa-similar` a spelling variant or synonym already open is added anyway and named.
- `alexa-read` reads the open items in aisle order: up to ten, then „und N weitere“, but all eleven when there are exactly eleven; an empty list has its own sentence.
- `alexa-reprompt` asks once when nothing was understood, then gives up; nothing is added.
- `alexa-unlinked` asks to link the account (a link card in the Alexa app) when there is no link or it was cut.
- `alexa-link` account linking: Alexa app → Skills → Snacklist → „Zur Verwendung aktivieren“ / „Konto verknüpfen“ opens Snacklist's consent page „Zugriff erlauben?“ for „Amazon Alexa“; after „Erlauben“ it shows „Verbunden“ / „Fertig, du kannst zu Amazon Alexa zurückkehren.“ until the Alexa app takes over; afterwards Mehr → Zugänge lists „Amazon Alexa“ under „Verbundene Apps“.
- `alexa-revoke` Alexa is cut off at once by „Amazon Alexa trennen“ then „Trennen“ in Zugänge, or by disabling the skill in the Alexa app; linking again restores it. Disabling the skill also removes „Amazon Alexa“ from Zugänge at once („Noch keine App verbunden.“ when it was the only app). What the server kept about the connection (link, add counter) goes at once either way; a connection unused for 12 months (also one only unlinked in the Alexa app) is removed with its Zugänge entry by a daily job.
- `alexa-help` help and stop.
- `alexa-verify` requests not signed by Amazon, stale or for another skill are refused (HTTP 400) before anything is read.

## How to get to it (user POV)

- Today (beta): get the beta invitation link from Peter, accept it with the Amazon account used for Alexa, open the skill „Snacklist“ in the Alexa app (its icon carries the note „dev“ in test), tap „Zur Verwendung aktivieren“, sign in to Snacklist, check „Zugriff erlauben?“ shows „Amazon Alexa“ and tap „Erlauben“. Needs an Alexa device set to German or English, a Snacklist account, a household, and the Alexa app. Published guide: „Snacklist per Alexa: Skill einrichten“ on snacklist.app. The old skill „Hummlist“ (invocation „humm list“, its beta without testers) is still served by the same endpoint until S5; the Snacklist skill (development stage) runs the beta with Lea and Max since job 174. Both answer as Snacklist since S4 (`docs/ALEXA.md`, Deploy; `supabase/functions/alexa/handler.ts:1-2`).
- Invocation: „Alexa, sag Snacklist, …“, „Alexa, frag Snacklist, …“, „Alexa, öffne Snacklist“. Invocation name: „snacklist“ in all six locales (S4, 2026-11-10; Hummlist used „humm list“, Q75). Only these patterns reach the skill: „Alexa, setz Milch auf die Snacklist“ goes to Alexa's own lists („Ich konnte keine Liste finden unter Snacklist“). Alexa may mishear the name or answer „Ich weiß nicht“; the guide says to say it clearly in two syllables, „Snack-list“, or start with „Alexa, öffne Snacklist“.
- Skill icon: the app icon (yellow hex ring with a check on cobalt, the same design as `app/web/icons/Icon-512.png` without its rounded corners), 108 and 512 px, generated by `design/app-icon/build.mjs`.
- Add phrases (sample utterances): „füg {items} hinzu“, „füge {items} hinzu“, „füg {items} zur liste hinzu“, „füg {items} zur einkaufsliste hinzu“, „{items} hinzufügen“, „setz {items} auf die liste“, „pack {items} auf die liste“, „setz {items} drauf“, „pack {items} drauf“, „schreib {items} drauf“, „füg noch {items} hinzu“, „ich brauche noch {items}“, „schreib {items} auf“, „trag {items} ein“, „notier {items}“, „wir brauchen {items}“, „ich brauche {items}“, „{items} auf die liste“, „dass wir {items} brauchen“ and more. Read phrases: „was steht auf der liste“, „was auf der einkaufsliste steht“, „was wir brauchen“, „was muss ich kaufen“, „lies die liste vor“, „die liste“ and more. Item names given in lower case are capitalized the German way („milch ohne laktose“ becomes „Milch ohne Laktose“).
- English (an Alexa device set to English): "Alexa, ask Snacklist to add milk and eggs", "Alexa, tell Snacklist we need milk", "Alexa, ask Snacklist what's on the list", "Alexa, open Snacklist". Replies: "I put milk and eggs on Snacklist.", "Already on Snacklist: milk.", "There are 3 things on your Snacklist: milk, eggs and bread." (more than eleven: "… and 2 more."; exactly eleven are all read), "Your Snacklist is empty.", launch "What should go on the list?", stop "Bye for now.", unlinked "Please link your Snacklist account in the Alexa app first. I sent you a card there." (`supabase/functions/alexa/speech_en.ts`). Names are stored as heard ("milk"), like Siri in English.
- Exact spoken replies in German:
  - one item added: „Ich habe Milch auf die Snacklist gesetzt.“
  - several added: „Ich habe Milch und Eier auf die Snacklist gesetzt.“ / „Ich habe Milch, Eier und Brot auf die Snacklist gesetzt.“
  - mix: „Ich habe Eier auf die Snacklist gesetzt. Schon auf der Snacklist: Milch.“
  - already there only: „Schon auf der Snacklist: Milch.“ A plain name whose item is open with a brand or the note Bio (and no other details), also in singular or plural, gets one yes/no question (job 112, Peter Q79; `Dialog.ConfirmIntent`, request line `-> ask`): „Butter“ with Butter (Weihenstephan) open asks „Butter Weihenstephan steht schon auf der Snacklist. Soll ich Butter trotzdem dazuschreiben?“ (EN "Butter Weihenstephan is already on Snacklist. Should I add butter anyway?"; listed in `site/COPY_NEEDED.md`). Yes: „Ich habe Butter auf die Snacklist gesetzt.“ (a second Butter); no: „Schon auf der Snacklist: Butter Weihenstephan.“; no answer: the session ends, nothing added. „Butter“ with „Butter gesalzen“ open (details gesalzen: another product, like passiert or laktosefrei) just adds: „Ich habe Butter auf die Snacklist gesetzt. Schon auf der Snacklist: Butter gesalzen.“
  - similar (a spelling variant or synonym is open, the new item is added anyway): it joins the „Schon auf der Snacklist:“ sentence after the exact ones, each name once (job 68): „Ich habe Karotten auf die Snacklist gesetzt. Schon auf der Snacklist: Milch und Möhren.“
  - units are spoken out: 2 l becomes „2 Liter“, kg „Kilo“, g „Gramm“, ml „Milliliter“.
  - more than thirty things: the confirmation is followed by „Mehr als dreißig auf einmal gehen nicht; sag den Rest bitte noch einmal.“
  - read: „Auf der Snacklist stehen 3 Sachen: Milch, Eier und Brot.“ / one item „Auf der Snacklist steht eine Sache: Milch.“ / more than ten: „Auf der Snacklist stehen 12 Sachen: a, b, … und 2 weitere.“ (exactly eleven: all are read, „…, Teil9 und Teil10.“, job 112) / empty: „Die Snacklist ist leer.“
  - open (launch): „Was soll auf die Liste?“ (reprompt „Was soll auf die Liste? Sag zum Beispiel: Milch und Eier.“)
  - help: „Mit Snacklist setzt du Sachen auf eure Einkaufsliste. Sag zum Beispiel: füg Milch und Eier hinzu. Oder frag: was steht auf der Liste? Was möchtest du?“ (reprompt „Was soll auf die Liste? Oder frag: was steht auf der Liste?“)
  - stop / cancel: „Bis bald.“
  - not understood, first time: „Das habe ich nicht verstanden. Was soll auf die Liste?“ (reprompt „Was soll auf die Liste? Sag zum Beispiel: Milch und Eier.“); second time: „Das habe ich leider nicht verstanden. Ich habe nichts auf die Snacklist gesetzt.“
  - not linked / cut off: „Bitte verknüpfe zuerst dein Snacklist-Konto in der Alexa-App. Ich habe dir dort eine Karte dazu geschickt.“
  - no household: „Du bist noch in keinem Haushalt. Leg in der Snacklist-App einen an oder tritt einem bei, dann klappt es auch mit Alexa.“
  - too long: „Das war zu lang. Sag höchstens dreißig Sachen auf einmal. Ich habe nichts hinzugefügt.“
  - too many requests: „Das waren gerade sehr viele Sachen auf einmal. Warte bitte eine Minute, dann geht es weiter. Ich habe nichts hinzugefügt.“
  - add failed: „Entschuldigung, das hat gerade nicht geklappt. Ich habe nichts hinzugefügt. Versuch es bitte gleich noch einmal.“
  - read failed: „Entschuldigung, ich komme gerade nicht an die Snacklist. Versuch es bitte gleich noch einmal.“
  - The add and read answers also appear as a card titled „Snacklist“ in the Alexa app.
- Skill store text (not live): „Eure gemeinsame Einkaufsliste: Sachen per Zuruf auf die Snacklist setzen.“ English: "Your household's shared shopping list: add things to Snacklist by voice." The package is set to every country (`alexa/skill-package/skill.json`, `isAvailableWorldwide`); as a beta it reaches only invited testers.

## Driving it with Playwright

Preconditions:

- Alexa itself cannot be driven. Only the skill's server side is, over HTTP against the LOCAL stack, as `e2e/tests/alexa.spec.ts` and `alexa-en.spec.ts` do. `helpers/launch.sh` already runs `scripts/alexa-test-ca.sh` before it starts the stack (`supabase_up` in `scripts/lib.sh`); run it by hand only for a stack started some other way, then restart that stack. Then use `scripts/alexa-say.sh` or the helpers in `e2e/tests/alexa-helpers.ts` (`alexaRequest`, `addIntent`, `readIntent`, `postToAlexa`, `say`, `registerAlexaClient`, `linkAccount`). Never call production.
- The spec signs up its own accounts (peter and lea, max and nina) and needs no seed. Run: `scripts/verify.sh --only e2e -- tests/alexa.spec.ts tests/alexa-en.spec.ts` (3 + 1 tests). By hand on the demo-familie seed, link mia and watch the list in noah's browser context instead of lea's.

- **Link the account (UI part).** `linkAccount(...)` registers a confidential OAuth client named like Alexa and opens the authorize URL with PKCE and the Alexa redirect `https://layla.amazon.com/api/skill/link/<vendor id>` in the signed-in page. The consent page shows „Zugriff erlauben?“ and `getByText('Amazon Alexa')`; click `getByRole('button', { name: 'Erlauben' })`; the callback carries a code; exchange it for an access token with HTTP Basic.
- **Zugänge shows it.** `openMore(page, 'Zugänge')`; `page.getByText('Amazon Alexa').first()` is visible under „Verbundene Apps“.
- **Add.** `say(token, 'Milch und Eier')` returns the speech (`scripts/alexa-say.sh --url "$API" --token "$TOKEN" "Milch und Eier"` prints JSON with `.response.outputSpeech.text`): „Ich habe Milch und Eier auf die Snacklist gesetzt.“; in the partner's page `itemRow(lea, 'Eier')` is visible within 5 seconds without reload; both are under category „Kühlregal“ (`getByRole('heading', { name: 'Kühlregal' })`).
- **Duplicate / read / re-prompt / launch.** `say(token, 'Milch')` gives „Schon auf der Snacklist: Milch.“; `scripts/alexa-say.sh … --read` gives „Auf der Snacklist stehen N Sachen: …“; `say(token, 'äh')` then `--retry` gives the two not-understood sentences, `shouldEndSession` false then true; `--launch` with no token gives the link sentence and a `LinkAccount` card. Add `--locale en-US` for the English replies.
- **Revoke.** `getByRole('button', { name: 'Amazon Alexa trennen' }).click()`, `getByRole('button', { name: 'Trennen', exact: true }).click()`, `getByText('Noch keine App verbunden.')`; the next add answers the link sentence and adds nothing; the refresh token is refused. Or `--disable` (SkillDisabled); Zugänge then shows „Noch keine App verbunden.“ as well. Database: `alexa_links` and `alexa_rate` have no row for the user afterwards (`alexaRows` in e2e/tests/alexa.spec.ts).
- **Verify.** `--unsigned` and `--stale` answer HTTP 400 (`missing_signature`, `stale_timestamp`); no item is added.

## Gotchas

- The beta status is the product reality: do not say the skill is in the Alexa Skill Store or certified. The hold `alexa-certification` stays until Amazon certifies it.
- Two languages: de-DE is German; every en-* locale gets the same English model and replies. A request without a locale is German.
- A stack started before `scripts/alexa-test-ca.sh` ran does not trust the test CA: every signed request answers 400 before any intent. Restart the local stack after running the script.
- The local function trusts the test CA only in a local stack; a hosted project refuses it, and `scripts/alexa-say.sh` cannot reach a hosted project.
- No Premium lock: Alexa is free for good (Legal N-27). With the integration-lock switch on, Alexa still adds (`e2e/tests/integration-lock.spec.ts`), and Zugänge never shows „Pausiert“ under Amazon Alexa.
- Each request logs one line, `alexa: <type> <intent|-> <locale|-> linked=<bool> -> <kind> [reason] rid=… slot=… confirm=… ended=… error=… ms=…` (`rid` is the last 12 characters of Alexa's request id, `slot` a word count), with no user ids, tokens or item names (`docs/ALEXA.md`, "Request log").
- Every linking run adds a row „Amazon Alexa …“ to Zugänge; after a second link, match the row with `.first()` or count the rows.
- Real Alexa voice, the Alexa app linking screens and the beta invitation cannot be checked here. unverified (needs a real device and an Amazon account).
