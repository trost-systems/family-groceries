# Job 153: offline and sync indicator prototypes (comparison preview)

PR: https://github.com/trost-systems/family-groceries/pull/297 (draft, NOT FOR MERGE)

## What was built

A static comparison page at `/internal/sync-indicator` in the hummlist-site project:
`site/public/internal/sync-indicator.html`, `sync-indicator/sync.css` and `sync-indicator/sync.js`.
It shows six phones (390 × 844 pt, Dynamic Island, 34 pt home-indicator inset) with the list screen as it is after #288 and #294: the floating top bar with Anpassen, the floating add field and the tab pill.

| Frame | Offline | Sync failing (online) |
| --- | --- | --- |
| Current | crossed-out cloud next to Anpassen, sentence only as a tooltip | the "pending" cloud, the same as normal syncing |
| S1 Top banner | slim navy bar under the status bar, pushes the top bar and the list down 36 pt | yellow bar with "Erneut versuchen" |
| S2 Floating card | tip-card-style sticker under the top bar, over the list, with the full sentence | honey card, "Erneut versuchen" hex button |
| S3 Island | black capsule grows out of the island with the sentence for 3 s, then stays as a chin with icon and "Offline"; tap opens it. The chin reaches y 75, below the top bar's 58, so the bar and the list move down 20 pt while it shows | same, yellow icon and button |
| S4 Add field | cloud icon in the field, sunken face, the sentence small above the field | honey face, sentence with a "Erneut versuchen" link |
| S5 Tab pill | third pill segment with icon and "Offline"; the sentence peeks as a bubble for 3 s and on tap | warning-coloured "Sync" segment, bubble with the button |

Online shows nothing in S1 to S5. Coming back online flashes "Wieder online" / "Back online" in mint for 1.6 s, then the indicator leaves.
Toggles (below 720 px wide the page starts at 1:1, since Fit draws each phone at about 0.45): state (online, offline, sync failing), DE/EN, light/dark, motion/reduced, fit/1:1.
Reduced motion (the toggle or `prefers-reduced-motion`) keeps a 120 ms fade only: no slide, grow or push, and S3 starts small.
Long copy never sits in a hex pill (Peter, 2026-11-05): pills carry an icon and one word.

## Recommendation

S1. It is what Peter described (top, only when offline), it works the same on iOS, Android and the web, it never covers a row (it pushes them), and it has a slot for the failing action.
Runner-up S4: quieter, and it says where it matters that adding still works offline, but it is easy to read as an add-field error.
S3 draws over the status bar, needs the top bar to move down 20 pt for its chin, and imitates a system surface the app can't use; off iOS it is a plain capsule. S2 covers the top two rows for as long as the phone is offline. S5 is easy to miss.
