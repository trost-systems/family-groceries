# Job 167: internal work stays out of the testers' notes and the changelog

PR: https://github.com/trost-systems/family-groceries/pull/319

## What was built

- `internalReason` in `scripts/release/changelog.mjs`. It calls a commit internal when none of its
  changed paths reaches users, when its description has a `Changelog: skip` paragraph, or, without
  a `## Changelog` section, when its title is a `docs:`/`ci:`/`test:`-style commit. The allowlist
  and denylist are in `docs/RELEASE.md`, "Internal work stays out".
- `node scripts/release/changelog.mjs notes --lang de|en --previous-sha P --sha S` writes TestFlight's
  "What to Test" from the PRs' changelog items in the note's language (titles only for commits
  from before job 39). It replaces `scripts/release/notes.sh`, and `release.yml` calls it.
- The changelog `draft` and `record.mjs`'s late gated items use the same rule. The draft warns
  per left-out commit.
- Docs: `docs/RELEASE.md` (What to Test, Internal work stays out), `docs/CHANGELOG.md`
  (Collecting a release), `docs/DECISIONS.md` (Job 167).
